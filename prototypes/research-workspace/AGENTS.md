# Agent Instructions: Inference Insights

## What This Prototype Demonstrates

An automated research gallery that showcases AI inference engineering insights generated by Claude Code running autonomously 4x daily via macOS LaunchAgent. Each insight connects inference engineering concepts (KV cache sharding, speculative decoding, batching strategies) to Nathan's experience as a Big Data ML Engineer at FINRA and his cross-domain interests in music/signal processing and architecture.

This demonstrates mature AI agent orchestration: autonomous research loops with feedback-driven topic selection, structured content generation, and automated deployment — all running unattended on a local Mac.

## Architecture Decisions

- **Two-file content format**: Each insight produces a narrative `.md` + executable `.cells.json` (not .ipynb) to keep diffs readable and avoid jupyter dependencies
- **arXiv-only sources**: Security decision — restricts the unattended research loop to academic papers, avoiding prompt injection risks from arbitrary web content
- **LaunchAgent scheduling**: Runs 4x daily without requiring an active terminal session or remote infrastructure
- **Domain color mapping**: Reuses AI Builders Portal phase colors for four cross-domain categories

## Development

```bash
yarn dev:inference-insights    # Port 3009
yarn build:inference-insights  # Production build
```

## Gotchas

- Content files are fetched at runtime, not bundled — `data/` and `content/` dirs must be copied to dist during build
- The research loop writes directly to `data/` and `content/` then commits + pushes
- Domain filter uses phase color CSS vars from the design tokens

## Deployment

- Build: `yarn build:inference-insights`
- Production URL: `portfolio.cookinupideas.com/prototypes/inference-insights/`
- Content updates deploy automatically via the research loop's deploy-site.sh call
