# Welcome to your Research Workspace

Your vault is a personal knowledge base stored on persistent cloud storage.
Files you create here persist across sessions.

## Quick Start

### 1. Set a Learning Intention
Go to **Workspace > Intentions** and click **+ New Intention**.
Choose "Learn" to research a topic, or "Integrate" to synthesize across existing notes.

### 2. Run Claude Code
Open the **Terminal** panel and run:
```bash
claude
```
Ask Claude to research your stated intentions. It will create markdown files
in your vault with findings, code examples, and cross-domain connections.

### 3. Review & Edit
Use the **Editor** to review generated content. Your vault supports:
- **Wiki-links**: Type `[[filename]]` to link between files
- **Inline markdown**: Headers, bold, code blocks render as you type
- **Graph view**: See connections between your notes visually

### 4. Publish to Gallery
When you're happy with a piece, click **Publish** to share it in the
public gallery at portfolio.cookinupideas.com/prototypes/research-workspace/

## Vault Structure

```
/workspace/
  ├── README.md          ← you are here
  ├── inbox/             ← quick captures
  ├── insights/          ← single-article research
  ├── syntheses/         ← cross-article narratives
  └── architectures/     ← system diagrams + benefit framing
```

## Tips
- Files auto-save as you type
- Use `Ctrl+P` to quickly find files
- The graph view shows how your notes connect
- Claude Code can read and write files in your vault directly
